ADIVINHAAI 1.3 — PWA COMPLETO PARA GITHUB PAGES
===================================================

ARQUIVOS:
- index.html             Aplicativo AdivinhaAI 1.3 (jogo + Firebase CDN)
- manifest.webmanifest   Configuração de instalação do PWA
- service-worker.js      Cache para funcionamento offline do jogo
- favicon.ico           Ícone de aba/favoritos em navegadores
- icons/                Ícones PNG transparentes, adaptativos e iPhone/iPad
- .nojekyll              Configuração de publicação no GitHub Pages

COMO PUBLICAR:
1. Extraia ESTE ZIP no computador.
2. Acesse seu repositório GitHub Pages (novo ou existente).
3. Abra a pasta/branch que será publicada (em geral, main / raiz).
4. Envie TODO o CONTEÚDO extraído à raiz do repositório, preservando a pasta icons/.
5. O arquivo inicial precisa se chamar index.html exatamente.
6. Em Settings > Pages, escolha Deploy from a branch e main / (root), se ainda não estiver habilitado.
7. Acesse https://SEU-USUARIO.github.io/NOME-REPOSITORIO/ (ou domínio que configurou).
8. No Android Chrome, abra Configurações > Instalar AdivinhaAI ou menu ⋮ > Instalar aplicativo.
   No iOS Safari, toque em Compartilhar > Adicionar à Tela de Início.

ATENÇÃO: NÃO carregue o ZIP sem extrair; envie os arquivos que estão DENTRO dele.

CONFIGURAÇÃO FIREBASE:
- No Firebase Authentication, ative Google, E-mail/Senha e Anônimo.
- Em Authentication > Configurações > Domínios autorizados, adicione SEU-USUARIO.github.io
  (ou o domínio personalizado efetivamente usado).
- Crie o Firestore e publique regras que permitam apenas o UID autenticado:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /usuarios/{userId}/dados/{docId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

FUNCIONAMENTO OFFLINE:
- A interface e o banco de perguntas embutido são armazenados no dispositivo pelo Service Worker.
- O primeiro carregamento deve ocorrer conectado à internet para gerar o cache.
- Login Google, e-mail e sincronização Firestore precisam de internet.
- Arquivos MIDI da internet também precisam de conexão quando não estiverem disponíveis localmente.
- Dados pessoais não são guardados no cache do Service Worker; o jogo já possui dados locais por perfil.

ATUALIZAÇÃO DE VERSÃO:
- Substitua os arquivos de sua versão anterior por TODOS os deste ZIP.
- Não mantenha duas versões de index.html, manifest ou service-worker com nomes diferentes.
- Em alterações futuras, incremente CACHE_NAME no service-worker.js para substituir caches antigos.
- Se a aba estiver aberta no celular, feche e abra novamente depois da publicação.

IMPORTANTE: Instalar diretamente um HTML local (file://) NÃO ativa a instalação PWA.
A instalação é oferecida pelo navegador e pode variar conforme dispositivo e critérios de uso.
